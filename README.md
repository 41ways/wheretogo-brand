# 행선지4: Brand

브랜드 1,603개 가운데 오늘의 브랜드를, 정답과 **몇 번째로 닮았는지**만 보고 맞히는 하루 한 문제 게임. 제일 적게 불러 맞힌 사람이 1등.

**하기 → https://41ways.github.io/wheretogo-brand/**

- 매일 자정(KST)에 1,603개 중 하나가 정답. 럭셔리 하우스부터 곡물 무역회사(카길), 작은 국내 브랜드까지 전부 정답 후보
- 부르면 정답과 닮은 **순서**와 그 순서로 매긴 100점 만점 점수(한 계단 0.06점)를 알려 줌. 유사도 수치는 브라우저에 안 나감
- 부른 곳이 어떤 특징에서 정답과 특히 닮았으면(그 특징에서 정답과 가장 닮은 5% 안) **닮은 점**으로 알려 줌 — 예: 상품 · 가격대
- 지도는 닮은 브랜드끼리 모이게 펼친 **의미 지도**(t-SNE). 점을 눌러 부르고, 확대하면 이름이 보임
- 하루 한 판 · 무한 모드 · 하드 모드(지도 도움 없음), 순위표는 행선지와 같음

## 닮음은 어떻게 재나

[41ways/brand-embedding](https://github.com/41ways/brand-embedding) 에서 브랜드마다 모은 특징 11개 묶음을 임베딩하고, 두 브랜드가 **둘 다 가진 묶음만으로** 코사인 가중 평균을 낸다.

| 묶음 | 가중치 |
|---|---|
| 설명(요약글, bge-m3) | 0.32 |
| 상품 종류(bge-m3) | 0.115 |
| 이미지(브랜드 원형 12유형) · 업종 | 0.09 · 0.09 |
| 창업·소유 · 시가총액 | 0.08 · 0.08 |
| 대표 가격대 · 출신 | 0.07 · 0.06 |
| 업계 안 위치 · 인지도 · 소속 그룹 | 0.045 · 0.035 · 0.015 |

가중치는 "A 는 C 보다 B 에 가깝다" 정답 세트의 학습 문항으로 격자 탐색해 골랐다.

## 구조

| 경로 | 하는 일 |
|---|---|
| `index.html` | 게임 화면. 행선지 원본을 `build/port/port.py` 로 바꿔 만든다 — 손으로 고치지 않는다 |
| `data/brands.json` | 브랜드 이름·별칭·업종·지도 좌표 (화면과 서버가 같이 씀) |
| `worker/` | 정답·점수·순위 서버 — Cloudflare Worker `wheretogo-brand` + D1 `wheretogo-brand` |
| `worker/src/model.json` | 압축한 유사도 모델 |

워커는 1,603×1,603 유사도표를 들 수 없어서, 정답 한 줄을 요청 때 계산한다(중앙 2ms). 설명·상품 임베딩은 평균을 빼지 않는 SVD 로 128·96차원까지 줄이고 int8 로 담았다. 원본과 순위 상관 0.997, 상위 10 겹침 95%.

## 다시 만들기

```sh
# brand-embedding 에서 모델·브랜드 목록
cd ../brand-embedding && python3 embed/preview.py && python3 embed/export_game.py ../wheretogo-brand
# 화면 — 행선지 원본이 바뀌었으면 다시
python3 build/port/port.py ../wheretogo/index.html index.html
# 서버
cd worker && node test-game.js && npx wrangler deploy
```

정답 순서는 비밀값 `ANSWER_SALT` 로 섞는다. 모델을 바꾸면 그날부터 점수 순서가 바뀌므로, 판이 진행 중인 날에는 배포를 피한다.
